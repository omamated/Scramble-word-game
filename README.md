# Scramble word game

I made this word game because I feel that wordle and everything have gotten too repetitive. I know games like this exist, but I wanted to test my python skills. I decided to use customtkinter for the nice gui and I used many modules that you can see in the code to get definitions and pick a random word.

I added different modes, whose difficulty are based on how common and long the word is. I also made a timed mode where you are given 60 seconds to get as many words unscrambled as you can. I also made it so when you press enter it submits the word and your cursor auto focuses onto the text box.

Your score is kept at the bottom for that session, the definition hint provides you with the definition of the word to assist you with figuring out the word.
# How to Run

To run this please download and run the exe in releases,


## Features
- Multiple difficulty levels
- Timed game mode
- Score and streak tracking
- Definition hints
- Randomized words
